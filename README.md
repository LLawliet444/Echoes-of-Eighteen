# 重返18岁

> 春风若有怜花意，可否许我再少年。

## 这是什么

一个记忆考古工具。通过选择题引导，逐步挖掘用户 18 岁时的生命结构——空间、期待、沉浸、关系、物件、习惯、未完成之物、普通的一天，以及它们如何延续到今天。

18岁是一个特殊的坐标——它是童年的终点和成年的起点。从这一年开始，你开始做出真正影响后来人生的选择。

## 核心信念

本技能不是为了重返18岁。本技能是为了寻找那些从18岁开始，一路延续到今天的动作、关系、习惯、未完成之物与生命轨迹。过去没有消失。过去参与了现在。

## 交互方式

- 选择题推进（A-D + E"我自己说"+ F"下一章"）
- 每轮先有一段时代画面短文（3-6行），再提问题
- 中间过程对用户黑箱
- 用户可随时回复"差不多了"进入最终报告
