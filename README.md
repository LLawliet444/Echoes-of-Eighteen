# 重返18岁

> 春风若有怜花意，可否许我再少年。

## 关于这个作品
这不是一个冰冷的问卷，而是一次灵魂的折叠。

邀请你潜入时间的深海，去打捞那个十八岁的自己。不是为了怀旧，也不是为了修补，而是为了看清那条无形的丝线——它的一端握在那个青涩的少年手中，另一端，正牵引着此刻的你。

## 核心信念
时间不会倒流。
生命始终连续。
过去存在现在。

你所经历的一切，最终都构成了此刻的你。

## 交互方式

- 选择题推进（A-D + E"我自己说"+ F"下一章"）
- 每轮先有一段时代画面短文（3-6行），再提问题
- 中间过程对用户黑箱
- 用户可随时回复"差不多了"进入最终报告
